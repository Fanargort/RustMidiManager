# Rust MIDI Manager

Скачивание для Windows x64 — в разделе [Releases](https://github.com/Fanargort/RustMidiManager/releases).

В обновлённой версии медиатека открывается при запуске. Светлая и тёмная темы переключаются в боковой панели и сохраняются после перезапуска. Обновлены список треков, обозначения горячих клавиш и плеер.

## MP3 → MIDI в версии 1.1.0

Нажмите **MP3 → MIDI**, выберите MP3 или WAV и задайте диапазон мелодии. Нажмите **Создать MIDI** и выберите место сохранения. Результат автоматически добавится в медиатеку. Поддерживаются записи длительностью до 10 минут, обработку можно отменить.

Конвертер экспериментальный и создаёт одну линию нот. Лучше всего подходят сольный инструмент или отчётливый голос. В полноценной песне бас и аккомпанемент могут влиять на выбор нот. Проверки включают тестовый MP3 с известной нотой. Качество выделения мелодии из сложных песен требует проверки на конкретном аудио.

## Запуск

Откройте **RustMidiManager.exe** на Windows x64. В автономную сборку включена среда .NET 10. При первом запуске ей может понадобиться несколько секунд, чтобы распаковать компоненты.

1. Нажмите **＋ MIDI**, **Импорт папки** или перетащите файлы и папки в окно. Поддерживаются файлы `.mid` и `.midi` форматов SMF 0 и 1.
2. Проверьте путь Steam-установки Rust в **Настройках**. Если автоматический поиск не сработал, в Steam откройте меню Rust → **Управление** → **Просмотреть локальные файлы** и укажите эту папку.
3. Откройте **Горячие клавиши**, выберите композицию и назначьте свободную клавишу. Например, назначьте две песни на F6 и F7.
4. В Rust откройте F1 и выполните `writecfg`, чтобы мастер увидел текущие сохранённые привязки.
5. В приложении откройте **Мастер настройки**. Выберите **Сразу проигрывать по клавише**. Просмотрите найденные конфликты. Перенесите команды в консоль F1 по одной, завершив строкой `writecfg`.
6. В игре экипируйте музыкальный инструмент. Нажмите одну из назначенных клавиш. Для следующей песни нажмите её клавишу.

Выбор в медиатеке и трее управляет локальным плеером. В него входят пауза, остановка и громкость. Для звука используется MIDI-устройство Windows по умолчанию. Исходные файлы сохраняются при удалении композиции из каталога.

## Восстановление клавиш

На странице **Горячие клавиши** нажмите **Восстановить привязки**, выберите снимок и вручную выполните команды из окна в Rust. Команды возвращают только клавиши из выбранного набора. Для ранее свободных клавиш мастер формирует `bind <key> ""`. Проверьте результат в меню управления Rust. Если после настройки вы меняли эти клавиши вручную, восстановление заменит их значениями из снимка.

Rust MIDI Manager читает сохранённые привязки и сохраняет копию перед экспортом. Встроенные назначения из `keys_default.cfg` тоже учитываются, если файл присутствует. Снимки и каталог сохраняются в `%LOCALAPPDATA%\RustMidiManager`. По умолчанию отдельные копии MIDI находятся в подпапке `MIDI`. В папку `instruments` Rust копируются файлы с безопасными именами на основе SHA-256. Для проверки изолированного профиля можно запустить `RustMidiManager.exe --data-dir "C:\путь\к\профилю"`.

## Что подтверждено документацией

Facepunch описывает каталог `instruments`, команду `instruments.playrecording <filename>` без расширения, прямую привязку команды к клавише и сохранение через `writecfg`. Wiki также описывает общий синтаксис прямого цикла `~первая;вторая`. [Инструменты](https://wiki.facepunch.com/rust/Instruments) · [Клавиши Rust](https://wiki.facepunch.com/rust/Keybinds)

Режим ПКМ с командами `instruments.overrideautoplay` и `instruments.clearautoplayoverride`, а также цикл MIDI помечены как экспериментальные. Их поведение в установленном игровом клиенте не проверялось. В настройке используются отдельные клавиши, текущая привязка ПКМ сохраняется. Динамическая смена автоплея из приложения и обратный цикл не реализованы. Игра управляет своим состоянием через команды, которые игрок применяет в F1.

## Проверка в Rust

- [ ] Сохраните исходные привязки через `writecfg`. Назначьте две свободные клавиши, скопируйте команды из мастера и выполните последнюю строку `writecfg`.
- [ ] С инструментом в руках нажмите обе клавиши. Проверьте, что каждой соответствует свой MIDI. Перезапустите Rust и снова нажмите обе клавиши.
- [ ] Для отдельной проверки ПКМ сформируйте экспериментальный набор. Проверьте в консоли, принимает ли клиент `instruments.overrideautoplay` и `instruments.clearautoplayoverride`. Если принимает, сравните мелодии при удержании ПКМ после F6 и F7 и проверьте клавишу сброса.
- [ ] Если включали цикл, проверьте переход по всему плейлисту и возврат к первой композиции. Если цикл не срабатывает, сформируйте набор из отдельных клавиш.
- [ ] Выполните команды восстановления из мастера. Сравните настройки управления с исходными. Проверьте, что обычное поведение ПКМ сохранилось.

## Сборка из исходников

Потребуется .NET 10 SDK на Windows. Распакуйте архив исходников в папку и выполните команды из неё:

```powershell
dotnet run --project RustMidiManager.Tests -c Release
dotnet publish RustMidiManager -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o release
```
