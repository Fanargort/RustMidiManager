# Rust MIDI Manager v1.0.0

Скачайте `RustMidiManager.exe` из раздела **Assets** и откройте его на Windows x64. Среда .NET входит в сборку.

- Импорт MIDI-файлов и папок, поиск, избранное и плейлисты.
- Локальное предпрослушивание с паузой, остановкой и регулировкой громкости.
- Поиск установки Rust через Steam и копирование MIDI в папку `instruments`.
- Мастер игровых клавиш с проверкой сохранённых привязок, резервной копией и экспортом команд для консоли F1.

Основной режим запускает композицию по назначенной клавише через `instruments.playrecording`. Режим ПКМ и цикл плейлиста экспериментальные. Сборка запускалась на Windows и прошла 19 автоматических проверок. Воспроизведение внутри Rust требует ручной проверки.

Обновлённый интерфейс включает светлую и тёмную темы с сохранением выбора, новый вид медиатеки, горячих клавиш и плеера.
