# Rust MIDI Manager v1.1.0

- Добавлена кнопка MP3 → MIDI с поддержкой MP3 и WAV до 10 минут.
- Распознавание одной мелодической линии с выбором диапазона нот.
- Сохранение MIDI с автоматическим импортом в медиатеку.
- Прогресс обработки и отмена.

Конвертер экспериментальный. На сложных песнях возможны ошибки выбора нот. Лучше работает с сольным инструментом или отчётливым голосом.

Скачайте RustMidiManager.exe из Assets. Закройте прежнюю версию перед запуском.

Пройдены 23 проверки, включая декодирование тестового MP3 и распознавание ноты. Проверен запуск приложения.
